# Academic Homepage Template

## Files
- `index.html` — sections, top navigation, profile links, and placeholder content
- `style.css` — visual design and mobile layout
- `profile.jpg` — optional profile photo (add your own)
- `cv.pdf` — optional CV PDF (add your own)

## Preview
Open `index.html` in a browser. Google Fonts and Font Awesome icons use CDN links, so those elements need an internet connection.

## Publish on GitHub Pages
1. Create a **public** GitHub repository named exactly `<your-github-username>.github.io`.
2. Put `index.html` and `style.css` in the repository root.
3. Commit and push to the `main` branch.
4. Open **Settings → Pages**. Under Build and deployment, select **Deploy from a branch**, then choose `main` and `/(root)`.
5. After deployment, visit `https://<your-github-username>.github.io/`.

## Customize
- Replace `Your Name`, bracketed text such as `[University Name]`, and placeholder URLs (`href="#"`) in `index.html`.
- Navigation items link to sections by their `id`; keep these in sync if you rename a section.
- Add a portrait named `profile.jpg` beside `index.html`; otherwise a placeholder appears.
- Add `cv.pdf` beside `index.html` if you want the CV link to work.
- Copy a `.publication` or `.timeline-item` block to add more entries.
- Remove sections or social links you do not need.
